# Bedrock Stuff

[English](#english) | [中文](#中文)

## English

A Fabric mod that adds classic **Bedrock Edition** blocks to Minecraft: Java Edition.

### Blocks

| Block | Description |
|-------|-------------|
| Glowing Obsidian | Obsidian that glows at light level 15, with very high blast resistance. Cannot be moved by pistons. |
| Nether Reactor Core | The classic core block from the legacy Pocket Edition Nether Reactor. |
| Hardened Glass | A blast-resistant glass that drops itself when broken. |
| Hardened Stained Glass | Hardened Glass in all 16 dye colors. |
| Hardened Glass Pane | Hardened Glass in pane form. |
| Hardened Stained Glass Panes | Hardened Glass Panes in all 16 dye colors. |

Adjacent hardened glass blocks of the same type cull their shared faces, just like vanilla glass.

### Requirements

- Minecraft **1.21.11**
- Fabric Loader **>= 0.18.4**
- Fabric API

### Building

```bash
./gradlew build
```

The built jar can be found in `build/libs/`.

## 中文

一个把经典的**基岩版**方块带到 Java 版的 Fabric 模组。

### 方块列表

| 方块 | 说明 |
|------|------|
| 发光黑曜石 | 亮度 15 的发光黑曜石，爆炸抗性极高，不可被活塞推动。 |
| 下界反应核 | 源自旧版携带版下界反应器的经典核心方块。 |
| 强化玻璃 | 高强度玻璃，破坏后掉落自身。 |
| 强化染色玻璃 | 全部 16 种染色的强化玻璃。 |
| 强化玻璃板 | 玻璃板形态的强化玻璃。 |
| 强化染色玻璃板 | 全部 16 种染色的强化玻璃板。 |

同种强化玻璃相邻放置时会隐藏共用面，与原版玻璃行为一致。

### 环境要求

- Minecraft **1.21.11**
- Fabric Loader **>= 0.18.4**
- Fabric API

### 构建

```bash
./gradlew build
```

构建产物位于 `build/libs/` 目录。
